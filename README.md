# Explainable AI for Credit Risk Assessment and Loan Approval

## Description

An Explainable AI framework for predicting credit risk and loan approval using Machine Learning and SHAP-based interpretability.

## Tech Stack

- Python
- Scikit-Learn
- SHAP
- FastAPI
- React
- Tailwind CSS
- XGBoost
- LightGBM

## Dataset

Home Credit Default Risk (Kaggle)
